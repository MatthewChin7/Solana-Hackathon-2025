# Strategy Marketplace - Solana Hackathon 2025

A complete Solana-based strategy marketplace with Polymarket integration, featuring NFT-gated strategy access and real-time prediction market signals.

## Overview

This project implements a 3-tier architecture:

1. **On-chain Program** (Anchor): Strategy NFTs, marketplace, and oracle updates
2. **Off-chain Server**: Polymarket integration with NFT-gated API
3. **Frontend** (Next.js): Wallet connection and signal fetching UI

## Prerequisites

### Toolchain Installation

```bash
# Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Solana CLI (Anza installer)
sh -c "$(curl -sSfL https://release.anza.xyz/stable/install)"

# Node.js (LTS) via nvm
nvm install --lts
nvm use --lts

# pnpm
npm install -g pnpm

# Anchor via AVM
cargo install --git https://github.com/coral-xyz/anchor avm --locked
avm install latest
avm use latest
```

### Devnet Setup

```bash
# Configure Solana CLI for devnet
solana config set --url https://api.devnet.solana.com

# Generate keypair (if needed)
solana-keygen new -o ~/.config/solana/id.json

# Request airdrop
solana airdrop 2
solana balance
```

## Setup Instructions

### Step 1: Build and Test the Anchor Program

```bash
# Install dependencies
pnpm install

# Build the program
anchor build

# Run tests
anchor test
```

### Step 2: Bootstrap Devnet

This script deploys a real strategy on devnet and generates all configuration files:

```bash
pnpm bootstrap:devnet
```

This will:
- Create creator and buyer keypairs
- Deploy a payment mint
- Create a strategy NFT
- List and buy the strategy
- Generate `.env` files for server and frontend
- Create `config/addresses.json`

### Step 3: Start the Server

```bash
cd packages/server
pnpm install
pnpm dev
```

The server will:
- Connect to Polymarket API
- Update signals every 60 seconds
- Expose NFT-gated `/signal` endpoint
- Run on http://localhost:4000

### Step 4: Start the Frontend

In a new terminal:

```bash
cd packages/frontend
pnpm install

# Copy IDL from Anchor build (required for frontend)
mkdir -p public/idl
cp ../../target/idl/strategy_marketplace.json public/idl/strategy_marketplace.json

# Start development server
pnpm dev
```

Visit http://localhost:3000

### Step 5: Connect Wallet and Test

1. Open Phantom wallet
2. Switch network to **Devnet**
3. Import the buyer keypair from `keys/buyer.json` (or send the Strategy NFT to your own wallet)
4. Connect wallet on the frontend
5. Click "Get Signal" to fetch the Polymarket-driven signal

## Features

### On-chain Program

- **Strategy NFTs**: 1-of-1 SPL tokens representing strategy ownership
- **Marketplace**: List and buy strategies with SPL payment tokens
- **Oracle Updates**: Store latest Polymarket mid prices on-chain
- **PDA-based Architecture**: Secure, deterministic account derivation

### Server

- **Polymarket Integration**: Fetches real-time mid prices from Polymarket API
- **Strategy Engine**: Converts mid prices to trading signals (BUY_YES/SELL_YES/HOLD)
- **NFT Gating**: Verifies wallet ownership before returning signals
- **Signature Verification**: Uses Ed25519 signatures for authentication

### Frontend

- **Wallet Integration**: Phantom, Solflare support via wallet-adapter
- **Strategy Display**: Shows on-chain strategy metadata and oracle data
- **Ownership Verification**: Checks NFT balance for connected wallet
- **Signal Fetching**: Signs message and requests signal from server

## API Endpoints

### POST /signal

Request:
```json
{
  "walletPubkey": "string",
  "message": "string",
  "signature": "base64 string"
}
```

Response:
```json
{
  "apiId": "strategy-1",
  "mid": 0.4523,
  "signal": "BUY_YES",
  "updatedAt": 1703123456
}
```

### GET /health

Returns server status and current signal availability.
